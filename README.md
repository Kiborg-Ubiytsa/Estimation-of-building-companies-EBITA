# Оценка прибыльности строительных компаний в России

## Общая информация
1. В первой части проекта подсчитывается EBITA компаний по данным, полученным с сайта https://bo.nalog.ru/ и проводится аналитика по полученному

2. Во второй части подсчитываются отношения чистой прибыли компаний относительно них самих N = 1,2,3,4 года назад (переменная x) и строятся распределения значения x по компаниям (графики y(x)). Далее проводится анализ перспективности отрасли на основе пунктов 1 и 2

3. В третьей части на географическую карту наносятся ТОП-500 компаний по суммарной выручке за 2021-2025 гг



## Как запускать проект
!Парсить данные как в пункте 1 не обязательно. Прилагаю csvшки со всем необходимым!

1. Запустите код из файла "Парсер JSON.ipynb" и получите данные с сайта https://bo.nalog.ru/. Для  этого вам понадобится файл с ИННами компаний "Реестр 1.xlsx", но он слишком большой, чтобы загружать его сюда

2. После этого данные сохранятся в файлы по годам типа "financial_data_2021.csv". Я привел свои файлы, этого будет достаточно для дальнейшей работы кода

3. Далее запустите код из файла "Подсчет EBITA" и посмотрите на результаты и из анализ

4. Аналогично с файлом "Графики y(x).ipynb"

5. В файле "ТОП500 на карте.ipynb" необходимо будет ввести API ключ, чтобы получить координаты всех. Для этого перейдите на сайт https://developer.tech.yandex.ru/services и оформите там API Геокодера. Его нужно скопировать и вставить по запросу программы. По итогу в этом файле отрисуется карта мира с нанесенными на нее 500 точками
